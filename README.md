# Carom

Carom is a browser-based top-down paddle duel. Move the paddles, curve the ball with spin, and use the central gold obstacles for bank shots. It includes Solo and local Versus modes.

## Install and run

```sh
npm ci
npm run dev
```

Open the Vite URL shown in the terminal. To create the static production site:

```sh
npm run build
```

The result is in `dist/` and can be served from the root of any static server.

## Controls

W/S move player one. In Versus, Up/Down move player two. Enter or Space confirms menus, P pauses, Escape backs out or pauses, and M toggles sound.
